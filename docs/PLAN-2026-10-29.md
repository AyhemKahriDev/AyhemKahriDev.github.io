## 3. Architecture / proposed approach

Keep the existing static-site generator and engine exactly as they are; add a **catalogue overlay layer** (`content/curated.json` for hand-written third-party picks, `content/overlays.json` for category/copy patches, merged by `scripts/catalogue.mjs`) so that harvest runs can never clobber curated copy again, then make the quality bar mechanical with two new zero-dependency gates (`scripts/audit-content.mjs`, `scripts/audit-size.mjs`) plus `node --test` unit tests for every pure generator. Six new games are built on the existing `GameSpec`/`GameInstance` contract with their puzzle logic in testable `src/shared/*.js` modules, and the six orphans are published only through `content/curated.json` after passing the existing browser validator.

**File:** `scripts/catalogue.mjs` (new) — implement to make it pass:

```js
/**
 * One catalogue, four layers, earlier layer wins, overlays last.
 *
 * `content/games.generated.json` is rewritten by every harvest run, so nothing
 * hand-written may live in it: curated third-party picks go in
 * `content/curated.json` and every patch goes in `content/overlays.json`.
 */
const COPY_KEYS = ['tagline', 'description', 'howToPlay', 'faq', 'keywords'];

export function mergeCatalogue({ base = [], curated = [], generated = [], overlays = {} }) {
  const byId = new Map();
  for (const game of [...base, ...curated, ...generated]) {
    if (!game || !game.id || byId.has(game.id)) continue;
    byId.set(game.id, { ...game });
  }

  for (const [id, patch] of Object.entries(overlays)) {
    const game = byId.get(id);
    if (!game) throw new Error(`overlays.json references unknown game: ${id}`);
    if (patch.category) game.category = patch.category;
    if (patch.title) game.title = patch.title;
    for (const key of COPY_KEYS) {
      if (patch.copy && patch.copy[key] !== undefined) game[key] = patch.copy[key];
    }
  }

  return [...byId.values()];
}
```

```js
/**
 * Deletes non-web files from a vendored game directory before it is copied
 * into dist/. Source of truth for the rules; called by copyThirdParty().
 *
 * Everything here was measured on the 2026-10-29 build: 705 files / 50.7 MB of
 * .apk, .zip, .psd, .md, .map, .git and android/ trees were being published as
 * if a browser could use them.

import { readdirSync, rmSync, statSync } from 'node:fs';
import { extname, join } from 'node:path';

const JUNK_EXT = new Set(['.apk', '.zip', '.psd', '.ai', '.map', '.md', '.markdown', '.yml', '.yaml', '.gitignore', '.npmignore', '.lock', '.log', '.exe', '.dmg', '.msi', '.swf']);
const JUNK_DIR = new Set(['.git', '.github', 'android', 'ios', 'node_modules', '__MACOSX', '.idea', '.vscode']);
/** Kept even inside a junk-looking directory: GitHub Pages projects publish from docs/. */
const KEEP = /(^|\/)docs\/(index\.html|[^/]+\.(js|css|png|jpg|jpeg|gif|webp|svg|mp3|ogg|wav|json|m4a))$/i;

export function pruneVendored(dir) {
  let removed = 0;
  let bytes = 0;
  const walk = (current) => {
    for (const entry of readdirSync(current, { withFileTypes: true })) {
      const p = join(current, entry.name);
      const rel = p.slice(dir.length + 1);
      if (KEEP.test(rel.replace(/\\/g, '/'))) continue;
      if (entry.isDirectory()) {
        if (JUNK_DIR.has(entry.name)) {
          bytes += dirSize(p);
          removed += rmSync(p, { recursive: true, force: true }) ?? 1;
          continue;
        }
        walk(p);
      } else if (JUNK_EXT.has(extname(entry.name).toLowerCase())) {
        bytes += statSync(p).size;
        rmSync(p, { force: true });
        removed += 1;
      }
    }
  };
  walk(dir);
  return { removed, bytes };
}

function dirSize(dir) {
  let total = 0;
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const p = join(dir, entry.name);
    total += entry.isDirectory() ? dirSize(p) : statSync(p).size;
  }
  return total;
}
```

```js
/**
 * Seeded sudoku. Pure, no DOM: unit-tested and shared with the site builder.
 * Measured: 3-7 ms to generate a unique puzzle on this machine.
 */
import { mulberry32 } from './daily.js';

export function candidates(grid, index) {
  const used = new Set();
  const r = Math.floor(index / 9);
  const c = index % 9;
  for (let k = 0; k < 9; k++) {
    used.add(grid[r * 9 + k]);
    used.add(grid[k * 9 + c]);
  }
  const br = Math.floor(r / 3) * 3;
  const bc = Math.floor(c / 3) * 3;
  for (let dr = 0; dr < 3; dr++) {
    for (let dc = 0; dc < 3; dc++) used.add(grid[(br + dr) * 9 + bc + dc]);
  }
  const out = [];
  for (let v = 1; v <= 9; v++) if (!used.has(v)) out.push(v);
  return out;
}

/** Up to `limit` solutions of `grid`. The input array is never mutated. */
export function solve(grid, limit = 2, rng = Math.random) {
  const work = grid.slice();
  const found = [];
  const step = () => {
    if (found.length >= limit) return;
    let pick = -1;
    let pickCand = null;
    for (let i = 0; i < 81; i++) {
      if (work[i] !== 0) continue;
      const cand = candidates(work, i);
      if (cand.length === 0) return;
      if (!pickCand || cand.length < pickCand.length) {
        pick = i;
        pickCand = cand;
        if (cand.length === 1) break;
      }
    }
    if (pick === -1) { found.push(work.slice()); return; }
    for (let k = pickCand.length - 1; k > 0; k--) {
      const j = Math.floor(rng() * (k + 1));
      [pickCand[k], pickCand[j]] = [pickCand[j], pickCand[k]];
    }
    for (const v of pickCand) {
      work[pick] = v;
      step();
      work[pick] = 0;
      if (found.length >= limit) return;
    }
  };
  step();
  return found;
}

/** A puzzle with exactly one solution and as close to `clues` givens as it can get. */
export function generateSudoku(seed, clues = 36) {
  const rng = mulberry32(seed);
  const solution = solve(new Array(81).fill(0), 1, rng)[0];
  const puzzle = solution.slice();
  const order = Array.from({ length: 81 }, (_, i) => i);
  for (let i = 80; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [order[i], order[j]] = [order[j], order[i]];
  }
  let removed = 0;
  for (const i of order) {
    if (81 - removed <= clues) break;
    const keep = puzzle[i];
    puzzle[i] = 0;
    if (solve(puzzle, 2, rng).length === 1) removed++;
    else puzzle[i] = keep;
  }
  return { puzzle, solution, clues: 81 - removed };
}
```

```ts
import type { EngineContext, GameInstance, GameResult, GameSpec, HudLine, Vec2 } from '../engine/types';
import { GRID_LINE, MUTED, PANEL, PANEL_2, TEXT, drawFitCenter, fillRound, setFont } from '../engine/render';
import { generateSudoku } from '../shared/sudoku.js';

const CLUES: Record<string, number> = { easy: 46, normal: 36, hard: 30 };

class Sudoku implements GameInstance {
  result?: GameResult;

  private grid: number[];
  private solution: number[];
  private fixed: boolean[];
  private selected = 40;
  private mistakes = 0;
  private seconds = 0;
  private over = false;

  constructor(private ctx: EngineContext) {
    const { puzzle, solution } = generateSudoku(ctx.seed, CLUES[ctx.difficulty] ?? 36);
    this.grid = puzzle.slice();
    this.solution = solution;
    this.fixed = puzzle.map((v) => v !== 0);
  }

  private geo() {
    const side = Math.min(this.ctx.width - 28, this.ctx.height - 96);
    const cell = Math.floor(side / 9);
    return { cell, x: (this.ctx.width - cell * 9) / 2, y: (this.ctx.height - cell * 9) / 2 + 14 };
  }

  update(dt: number): void {
    if (!this.over) this.seconds += dt;
  }

  pointerDown(p: Vec2): void {
    if (this.over) return;
    const g = this.geo();
    const c = Math.floor((p.x - g.x) / g.cell);
    const r = Math.floor((p.y - g.y) / g.cell);
    if (r < 0 || r > 8 || c < 0 || c > 8) return;
    this.selected = r * 9 + c;
    this.ctx.audio.play('tap', { gain: 0.25 });
  }

  key(e: KeyboardEvent): void {
    if (this.over) return;
    const r = Math.floor(this.selected / 9);
    const c = this.selected % 9;
    if (e.key === 'ArrowUp') this.selected = ((r + 8) % 9) * 9 + c;
    else if (e.key === 'ArrowDown') this.selected = ((r + 1) % 9) * 9 + c;
    else if (e.key === 'ArrowLeft') this.selected = r * 9 + ((c + 8) % 9);
    else if (e.key === 'ArrowRight') this.selected = r * 9 + ((c + 1) % 9);
    else if (/^[1-9]$/.test(e.key)) this.enter(Number(e.key));
    else if (e.key === 'Backspace' || e.key === 'Delete' || e.key === '0') this.enter(0);
    else return;
    e.preventDefault();
  }

  private enter(value: number): void {
    if (this.over || this.fixed[this.selected]) return;
    if (value === 0) {
      this.grid[this.selected] = 0;
      return;
    }
    this.grid[this.selected] = value;
    if (value !== this.solution[this.selected]) {
      this.mistakes += 1;
      this.ctx.audio.play('wrong', { gain: 0.12 });
      if (this.mistakes >= 3) this.finish(false);
      return;
    }
    this.ctx.audio.play('found', { gain: 0.5 });
    if (this.grid.every((v, i) => v === this.solution[i])) this.finish(true);
  }

  private finish(won: boolean): void {
    if (this.over) return;
    this.over = true;
    const previous = this.ctx.storage.number('best', 0);
    const score = won ? Math.max(200, 4200 - Math.floor(this.seconds) * 8 - this.mistakes * 400) : 0;
    const best = Math.max(score, previous);
    this.ctx.storage.set('best', best);
    this.ctx.storage.inc('plays', 1);
    this.ctx.audio.play(won ? 'win' : 'gameover');
    this.ctx.analytics.track('game_over', { game: 'sudoku', score, won, mistakes: this.mistakes });
    this.result = {
      score,
      best,
      record: score > previous,
      won,
      detail: won ? `${Math.floor(this.seconds)}s · ${this.mistakes} mistakes` : 'three mistakes - try again',
    };
  }

  hud(): HudLine[] {
    return [
      { label: 'Filled', value: `${this.grid.filter((v) => v !== 0).length}/81` },
      { label: 'Mistakes', value: `${this.mistakes}/3` },
      { label: 'Time', value: `${Math.floor(this.seconds)}s` },
    ];
  }

  render(ctx: CanvasRenderingContext2D): void {
    const g = this.geo();
    for (let i = 0; i < 81; i++) {
      const r = Math.floor(i / 9);
      const c = i % 9;
      const x = g.x + c * g.cell;
      const y = g.y + r * g.cell;
```

```js
import { mulberry32 } from './daily.js';

export function neighbours(index, rows, cols) {
  const r = Math.floor(index / cols);
  const c = index % cols;
  const out = [];
  for (let dr = -1; dr <= 1; dr++) {
    for (let dc = -1; dc <= 1; dc++) {
      if (!dr && !dc) continue;
      const nr = r + dr;
      const nc = c + dc;
      if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
      out.push(nr * cols + nc);
    }
  }
  return out;
}

export function countsFor(isMine, rows, cols) {
  const counts = new Array(rows * cols).fill(0);
  for (let i = 0; i < rows * cols; i++) {
    counts[i] = isMine[i] ? -1 : neighbours(i, rows, cols).filter((n) => isMine[n]).length;
  }
  return counts;
}

export function generateMines(rows, cols, mines, seed) {
  const total = rows * cols;
  const rng = mulberry32(seed);
  const order = Array.from({ length: total }, (_, i) => i);
  for (let i = total - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [order[i], order[j]] = [order[j], order[i]];
  }
  const isMine = new Array(total).fill(false);
  for (let k = 0; k < Math.min(mines, total - 9); k++) isMine[order[k]] = true;
  return { isMine, counts: countsFor(isMine, rows, cols), rows, cols };
}

/** Move the mine under the first click to the first free cell that is not a neighbour of it. */
export function applyFirstClick(field, index) {
  const { rows, cols } = field;
  if (!field.isMine[index]) return field;
  const isMine = field.isMine.slice();
  const blocked = new Set([index, ...neighbours(index, rows, cols)]);
  const target = [...Array(rows * cols).keys()].find((i) => !isMine[i] && !blocked.has(i));
  isMine[index] = false;
  if (target !== undefined) isMine[target] = true;
  return { isMine, counts: countsFor(isMine, rows, cols), rows, cols };
}

/** Every index a reveal at `start` opens: the empty region plus its numbered border. */
export function floodFrom(counts, start, rows, cols) {
  const seen = new Set();
  const queue = [start];
  while (queue.length) {
    const i = queue.pop();
    if (seen.has(i) || counts[i] === -1) continue;
    seen.add(i);
    if (counts[i] === 0) for (const n of neighbours(i, rows, cols)) if (!seen.has(n)) queue.push(n);
  }
  return [...seen];
}
```

```ts
import type { EngineContext, GameInstance, GameResult, GameSpec, HudLine, Vec2 } from '../engine/types';
import { GRID_LINE, MUTED, PANEL, PANEL_2, TEXT, drawFitCenter, fillRound, setFont } from '../engine/render';
import { applyFirstClick, floodFrom, generateMines } from '../shared/minesweeper.js';

const LEVELS: Record<string, { rows: number; cols: number; mines: number }> = {
  easy: { rows: 9, cols: 9, mines: 10 },
  normal: { rows: 12, cols: 12, mines: 22 },
  hard: { rows: 14, cols: 14, mines: 38 },
};

class Minesweeper implements GameInstance {
  result?: GameResult;

  private rows: number;
  private cols: number;
  private mines: number;
  private isMine: boolean[];
  private counts: number[];
  private open: boolean[];
  private flags: boolean[];
  private started = false;
  private flagMode = false;
  private seconds = 0;
  private over = false;

  constructor(private ctx: EngineContext) {
    const level = LEVELS[ctx.difficulty] ?? LEVELS.normal;
    this.rows = level.rows;
    this.cols = level.cols;
    this.mines = level.mines;
    const field = generateMines(level.rows, level.cols, level.mines, ctx.seed);
    this.isMine = field.isMine;
    this.counts = field.counts;
    this.open = new Array(level.rows * level.cols).fill(false);
    this.flags = new Array(level.rows * level.cols).fill(false);
  }

  private geo() {
    const side = Math.min(this.ctx.width - 24, this.ctx.height - 104);
    const cell = Math.floor(side / this.cols);
    return { cell, x: (this.ctx.width - cell * this.cols) / 2, y: (this.ctx.height - cell * this.rows) / 2 + 16 };
  }

  private indexAt(p: Vec2): number {
    const g = this.geo();
    const c = Math.floor((p.x - g.x) / g.cell);
    const r = Math.floor((p.y - g.y) / g.cell);
    if (r < 0 || r >= this.rows || c < 0 || c >= this.cols) return -1;
    return r * this.cols + c;
  }

  update(dt: number): void {
    if (this.started && !this.over) this.seconds += dt;
  }

  key(e: KeyboardEvent): void {
    if (e.key === 'f' || e.key === 'F') this.flagMode = !this.flagMode;
  }

  pointerDown(p: Vec2): void {
    if (this.over) return;
    const i = this.indexAt(p);
    if (i < 0) return;
    if (!this.started) {
      const field = applyFirstClick({ isMine: this.isMine, counts: this.counts, rows: this.rows, cols: this.cols }, i);
      this.isMine = field.isMine;
      this.counts = field.counts;
      this.started = true;
    }
    if (this.open[i]) return;

    if (this.flagMode) {
      this.flags[i] = !this.flags[i];
      this.ctx.audio.play('tap', { gain: 0.3 });
      return;
    }
    if (this.flags[i]) return;

    if (this.isMine[i]) {
      this.revealAll();
      this.finish(false);
      return;
    }
    for (const cell of floodFrom(this.counts, i, this.rows, this.cols)) this.open[cell] = true;
    this.ctx.audio.play('select', { gain: 0.35 });
    const safeTotal = this.rows * this.cols - this.mines;
    if (this.open.filter(Boolean).length >= safeTotal) this.finish(true);
  }

  private revealAll(): void {
    for (let i = 0; i < this.isMine.length; i++) if (this.isMine[i]) this.open[i] = true;
  }

  private finish(won: boolean): void {
    if (this.over) return;
    this.over = true;
    const previous = this.ctx.storage.number('best', 0);
    const score = won ? Math.max(120, 5000 - Math.floor(this.seconds) * 10) : 0;
    const best = Math.max(score, previous);
    this.ctx.storage.set('best', best);
    this.ctx.storage.inc('plays', 1);
    this.ctx.audio.play(won ? 'win' : 'gameover');
    this.ctx.analytics.track('game_over', { game: 'minesweeper', score, won });
    this.result = {
      score,
      best,
      record: score > previous,
      won,
      detail: won ? `cleared in ${Math.floor(this.seconds)}s` : 'boom - press R for a new field',
    };
  }

  hud(): HudLine[] {
    return [
      { label: 'Mines', value: `${this.mines - this.flags.filter(Boolean).length}` },
      { label: 'Mode', value: this.flagMode ? 'FLAG' : 'OPEN' },
      { label: 'Time', value: `${Math.floor(this.seconds)}s` },
    ];
  }

  render(ctx: CanvasRenderingContext2D): void {
    const g = this.geo();
    const colours = ['', '#4fa3ff', '#4fd18b', '#ffcc4d', '#ff9f6b', '#ff6b6b', '#c98cff', '#e0e0e0', '#9b978d'];
    for (let i = 0; i < this.rows * this.cols; i++) {
      const r = Math.floor(i / this.cols);
      const c = i % this.cols;
      const x = g.x + c * g.cell;
      const y = g.y + r * g.cell;
      fillRound(ctx, x + 1, y + 1, g.cell - 2, g.cell - 2, 4, this.open[i] ? PANEL_2 : PANEL, GRID_LINE);
      if (!this.open[i]) {
        if (this.flags[i]) {
          ctx.fillStyle = this.ctx.accent;
          drawFitCenter(ctx, 'F', x + g.cell / 2, y + g.cell / 2, g.cell - 8, g.cell * 0.5, 800);
        }
        continue;
      }
      if (this.isMine[i]) {
        ctx.fillStyle = '#ff6b6b';
        drawFitCenter(ctx, '*', x + g.cell / 2, y + g.cell / 2, g.cell - 8, g.cell * 0.7, 800);
      } else if (this.counts[i] > 0) {
        ctx.fillStyle = colours[this.counts[i]] ?? TEXT;
        drawFitCenter(ctx, String(this.counts[i]), x + g.cell / 2, y + g.cell / 2, g.cell - 8, g.cell * 0.55, 800);
      }
    }
    ctx.fillStyle = MUTED;
    setFont(ctx, 12, 600);
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText(`PRESS F TO ${this.flagMode ? 'STOP' : 'START'} FLAGGING · FIRST CLICK IS ALWAYS SAFE`, this.ctx.width / 2, g.y - 18);
  }
}

};
```

**Lights Out** — `src/shared/lightsout.js` + `src/games/lightsout.ts`.
- 5×5 always. `scramble(seed)` returns a `boolean[25]` built by applying `8 + (seed % 6)` random cross-toggles to an all-off board — solvable by construction.
- Tap toggles the cell and its orthogonal neighbours. Win when all 25 are off. `moves` counted; `hud()` = Moves, Lit.
- Test: `scramble(seed)` toggles exactly the cells implied by its own move list, and `solveByToggling` reaches an all-off board; same seed → same board.

**Simon** — `src/shared/simon.js` + `src/games/simon.ts`.

- Input window opens after playback; a wrong pad ends the round; a full repeat appends one step.
- Test: `sequence` is deterministic and every value is in `[0,3]`.

**Typing Sprint** — `src/shared/typing.js` + `src/games/typing.ts`.

- Input: `key()` appends printable characters, `Backspace` edits, `Space` submits.
- `hud()` = WPM, Correct, Time. `result` at time-out; `shareCard` prints WPM.
- Test: `wordQueue(seed, 20)` returns 20 unique words, all length 4–8, identical for the same seed.

## 12. Risks, tradeoffs, open questions

**Risks**
- **Deleting a vendored file a game actually loads.** `prune-vendored` only drops extensions no browser can execute and directories that are build tooling, plus `docs/` is explicitly kept. `audit:assets` + `audit:health` are the proof; a red `audit:health` after pruning means the rule was wrong, not the gate.
- **Category rebalance changes URLs?** No — `/categories/<id>/` for the three new ids are *new* pages; existing category URLs keep working. The 30 old `arcade` games that move will appear under `classics`/`racing`/`table`, and `/categories/arcade/` shrinks. Sitemap and internal links regenerate; `audit:links` verifies.
- **Copy rewrite is judgement, not code.** 57 games get templated control text, then twelve get hand-written descriptions. That is the only part of this plan a checker cannot fully verify — the `audit-content` regex catches repository language, not dull writing.
- **`node --test` + TS.** Tests cover `.js` generators only. Canvas behaviour stays the browser gates' job; do not pretend otherwise.
- **Wrangler major bump** could break the Cloudflare vite plugin. Runtime deps stay clean regardless; if the bump breaks the build, pin and accept the dev advisory.
- **Subagents editing `scripts/build-site.mjs` concurrently** will conflict. C1 finishes before C2 starts; C2 owns the file after that.

**Tradeoffs**
- Six new engine games beat sixty more harvested ones: unique copy, no licence surface, playable on a phone by construction. The catalogue stays at 180 rather than growing to 300 near-identical snake forks — the README already argues this ("a near-duplicate page is worse than fewer games").
- Per-game OG images (168+ cards) are deliberately **not** in scope: build cost and 20 MB of PNGs for a marginal social preview. YAGNI until the games rank.
- French/Arabic localisation is out of scope. The user speaks both, the site is English-only; that is a separate job with its own copy budget.

**Open questions for the user**
1. **Cloudflare deploy:** wire the repo in the dashboard, or provide a token for `~/.cf_token`? Without one, `arcadefork.pages.dev` (the canonical URL in every `canonical` tag, sitemap and OG tag) stays on the old build while GitHub Pages moves ahead — duplicate-content drift.
2. **Prune or publish the near-duplicate clones?** Plan keeps all 23 snakes and 15 tetrises and fixes their titles/category instead of deleting. Deleting is defensible for SEO but contradicts "add more games".
3. **Six orphans:** publish every one that paints, or only those with a distinct mechanic (wordle-craft, wordcloud, nova-lancer are distinct; the snake and tower clones are not)? Default in this plan: publish all that pass, since they are already vendored and validated cheaply.
